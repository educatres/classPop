ClassPop

上課即時回答系統

Firebase 即時同步版本。建立課程後即可產生主持頁、學生匿名作答頁、統計頁與 QR Code。

學生不需要註冊或登入帳號，前端會使用 Firebase Anonymous Authentication。每個課程自建立起保留 3 天；到期後停止讀寫，並於首頁偵測到過期課程時自動刪除。

Step 1

建立 Firebase 課程

主持頁不會把密鑰放在網址中。請記下這 6 位數，老師首次進入主持頁時需要輸入。

資料位置 classes/

題目、流程事件與匿名作答紀錄都會寫入此課程節點。

Firebase

第一次部署設定

  1. 在 Firebase Authentication 啟用「匿名」登入方式。
  2. 建立 Realtime Database，並確認 js/firebase-config.js 的專案設定正確。
  3. 使用專案內的 database.rules.json 部署安全規則。
  4. 網站本身可繼續部署在 GitHub Pages，不需要 Google Form、Google Sheet 或 Apps Script。
  5. 課程建立後，將學生作答連結或 QR Code 分享給學生即可匿名作答。
  6. 老師進入主持頁時以 6 位數密鑰登入；登入後才可控制題目與刪除課程。
